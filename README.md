# RelayPay Support Evals

**Product**  
RelayPay is a fictional app for fast, private payments between people.

**Component under test**  
The system uses RelayPay's internal documentation and an LLM to prepare suggested responses for customer support staff.

**Project goal**  
The goal is to evaluate how reliably this nondeterministic component handles realistic customer issues using a golden dataset, RAG, test oracles, and evals.
